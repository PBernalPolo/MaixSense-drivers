# MaixSense-drivers-java

A driver implementation for the MaixSense-A010 written in Java:

https://wiki.sipeed.com/hardware/en/maixsense/maixsense-a010/maixsense-a010.html


## Getting Started

This library is intended to be added as a submodule for use in another project.
That is what the repository [MaixSense-processingTester](https://github.com/pbernalpolo/MaixSense-processingTester) does.
It contains a number of usage examples and is a good starting point for becoming familiar with the library.
